## 모아에브리

사과 게임·핀볼·길건너기 등 여러 미니게임을 PC와 모바일에서 즐기는 웹 게임 플랫폼입니다. 

로그인하면 게임별 랭킹에 도전하고, 플레이로 출석과 경험치를 쌓을 수 있습니다.

**[모아에브리 플레이하기 →](https://moa-every.site/)**

**제작** 2026.11.19 – 11.22 · 전 과정 바이브 코딩 (GPT-6.2 Astra, Extra High)  
**기술 스택** React · Three.js · Node.js · PostgreSQL · Vercel
